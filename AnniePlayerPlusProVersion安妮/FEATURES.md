# 安妮播放器 Plus（AnniePlayerPlusVersion）功能与特性总览

> 版本：V1.1.2 ｜ 平台：Windows x64 ｜ 技术栈：Electron 42 + 自研 C# 音频引擎（.NET 8）
> 安装包：`AnniePlayerPlusVersionSetup/AnniePlayerPlusVersionSetup-V1.1.2.exe`

---

## 一、产品定位

一款面向音质发烧友与视觉体验派的本地 + 流媒体音乐播放器：
**专业级独占音频链路** × **双主题界面（粒子舞台 / 仿 foobar2000）** × **内建音频分析工具链**，
并独家整合网易云 / QQ 音乐流媒体与本地独占播放的无缝融合。

---

## 二、音频引擎与音质

| 特性 | 说明 |
|---|---|
| 解码 | ffmpeg → 32bit float PCM，覆盖 FLAC/APE/WAV/AIFF/ALAC/TTA/WV、DSD（DSF/DFF 转 PCM）、MP3/MP2/AAC/M4A/OGG/Opus/WMA/MKA 等 18 种扩展名 |
| 输出 | **WASAPI Exclusive（事件驱动）** 与 **ASIO（多客户端架构）** 双通道 |
| Bit-perfect | 源码率直通，设备不支持时引擎重采样并明确提示 |
| 容错 | 独占设备被占用时智能降级共享模式（而非直接报错） |
| 声道 | ASIO 支持 8 声道任选 L/R 映射 |
| 15 段 EQ | 32Hz~16kHz 标准倍频程，±12dB / 0.5dB 步进，RBJ peaking biquad 链在引擎 float PCM 域处理——独占链路内生效、增益热更新不断流、换歌自动重建；双界面共享同一 DSP 状态 |
| EQ 预设 | Flat / Pop / Rock / Jazz / Classical / Custom，支持重置、开关、数值输入 |

## 三、双主题界面

### 粒子舞台（legacy）
- Three.js 粒子视觉舞台：随节拍律动的粒子系统、专辑封面氛围背景（模糊交叉淡入）
- 频谱/波形可视化面板（可停靠收起的竖向工具条 + 画布）
- 浮动歌词层、BPM/调性徽章、工具提示条
- 底栏三段分层布局（V1.1.0 方案A）：**播放组**（主键 56px）｜**音频工具组**（收藏/频谱/EQ）｜**系统组**（音量/设备弹层）

### 仿 foobar2000（FB2K）
- 标题栏 + 菜单栏 + 左栏目录树 + 中央播放列表 + 右栏信息（封面/元数据/歌词/频谱）+ 底栏控制
- 虚拟滚动大列表、列排序（可切换升降序）、分组视图、三种视图模式（列表/分栏/封面）
- 右键菜单（播放/收藏/评分/属性/从列表移除）、属性弹窗、播放列表管理
- 底部 EQ 抽屉（与粒子舞台 EQ 实时互同步）

### 主题系统
- **双主题一键切换**：300ms 遮罩淡切，播放状态/队列完全连续
- **四配色方案**（粒子舞台）：暗夜金 / 靛蓝极光 / 翡翠深空 / 白昼，全部通过 WCAG AA 实算，设置面板卡片即时切换，防闪屏早标记
- **FB2K 暗色模式**（V1.1.2）：护眼暗色全组件覆盖（标题栏/菜单/树/列表/信息栏/底栏/右键菜单/弹窗/EQ 抽屉/滚动条），三入口切换（工具栏 🌙 / Ctrl+Shift+D / 设置面板），持久化
- 配色对比度标准：主文本 ≥13:1、次级 ≥7:1、控件边界 ≥3:1

## 四、曲库与索引

- **Worker 线程扫描**（worker_threads）：递归目录扫描、元数据解析（music-metadata）均在 Worker 内完成；每 100 首批量回传增量渲染；进度浮层「扫描中…已发现 X 首」可随时取消；Worker 崩溃自动降级同步扫描
- **粒子舞台平铺文件夹导航**（V1.1.0）：所有含曲目文件夹平铺显示并浅色标注归属主文件夹 → 点击进入仅显示该文件夹曲目（递归），返回栏一键回退
- **FB2K 目录树**：递归树形索引，展开/折叠 + 递归计数
- **跨主题索引定位**（V1.1.1）：播放中切换主题，目标界面索引自动展开/滚动定位到正在播放的文件
- 文件夹图标网格视图（🗂 旧逻辑完整保留）
- 搜索过滤（文件夹与曲目双模式响应）、多维度排序（名称/文件夹/修改时间/艺术家/专辑/流派/年份，拼音排序中文友好）
- 多播放列表、收藏（我的喜爱）、评分（星级）、标签缓存（metaCache 持久化）

## 五、性能工程

| 策略 | 实现 |
|---|---|
| 大列表虚拟滚动 | 粒子舞台/FB2K 双侧，5000+ 首 60fps |
| 排序/过滤 offload | >1000 首移交 Web Worker（listWorker），代际防过期写入 |
| 渲染防重入 | 渲染代际（renderGen）+ 负缓存防标签加载死循环（根治点歌失灵 bug） |
| 点击健壮性 | 容器级 pointerdown/pointerup 委托，行节点替换竞态下点击不丢 |
| 后台标签加载 | 批量拉取 + 增量重排，播放中不覆写队列 |
| 动效降级 | `prefers-reduced-motion` 全局降级 |

## 六、流媒体

- 网易云音乐、QQ 音乐：搜索、歌单、在线播放（经 ffmpeg 拉流解码进入同一独占链路）
- 扫码登录、流媒体音质选择（标准/极高/无损/Hi-Res，VIP 感知）

## 七、音频分析工具链（差异化亮点）

- **实时频谱**：FB2K 面板按播放进度对齐 FFT 帧（误差 ≤46ms，拖动进度条仍同步）
- **波形图**：整轨波形 + 播放位置游标，点击跳转
- **假无损检测**：整轨频谱分析识别假无损（竞品中罕见的内建功能）
- **节拍分析**：BPM/调性检测，驱动粒子舞台律动

## 八、歌词

- 同名 .lrc 自动匹配、时间轴解析、当前行高亮加粗、自动滚动居中（误差 <0.5s）
- 粒子舞台浮动歌词层 + FB2K 右栏歌词区（翻译行支持）
- 在线歌词搜索（流媒体源）

## 九、系统整合与交互细节

- 全局快捷键（播放/切曲/音量）、FB2K 快捷键组（Space/Ctrl+←→↑↓/F5/Delete/Ctrl+Shift+D）
- 系统托盘、任务栏缩略图播放控制按钮、窗口关闭最小化到托盘（可配）
- 侧栏宽度拖拽记忆、面板展开状态记忆、启动时恢复上次播放位置
- 微交互：播放键回弹、切歌封面交叉淡入 + 文本逐行滑入、收藏爆裂、按钮弹簧手感、弹层 popIn、扫描浮层呼吸

## 十二、Pro 版功能（AnniePlayerPlusProVersion beat0.0.1）

### 音质链路增强

- **DSD 原生输出**：DSF 原生 DSD 读取器（C# 直解 DSF 块结构）+ DoP 封装（0x05/0xFA 标记，176.4kHz/24bit WASAPI 独占直通）；设置三选一（转 PCM 默认 / DoP / Native），设备能力逐台探测（176.4k 不可达自动灰显 + 回退提示）；DFF 与 Native ASIO DSD 明确回退并 toast 说明
- **削波防护（DSP 链）**：EQ 段间硬削波移除，改为输出前两级防护——自动前级补偿（按 15 段最大正增益等量负前级，默认开）+ tanh 软限幅器（默认开），EQ 面板内开关，热更新不断流
- **响度归一化（EBU R128）**：ffmpeg ebur128 逐轨分析（Integrated LUFS + True Peak），目标 -16 LUFS；关闭/按曲目/按专辑三档（默认关）；真峰 headroom 联动防削波；未分析曲目播放时后台懒补算；旧曲库「补算响度」批量任务（分批落盘 + 进度 + 可取消）
- **Bit-perfect 直通状态**：底栏绿色圆点 + 「源码率/位深 → 输出采样率/位深」实时显示；重采样/DSD 转 PCM 时黄点 + 原因；FB2K 右栏格式行同步显示
- **缓冲与预载可配**：独占缓冲 50–500ms 滑杆（默认 50）、整轨预载到内存开关（解码队列容量按需扩展，上限 512MB）
- **交叉淡入（Crossfade）**：引擎内 CrossfadeMixer 双槽 float 混音，切歌同一输出流内淡入淡出（独占不断流），0–10s 步进 0.5（默认关）；手动切歌与自动连播均生效；采样率不一致时 ffmpeg 解码端自动对齐

### 曲库与管理

- **媒体库视图**：按 metaCache 标签聚合「专辑」（封面卡片网格，懒加载封面）与「艺术家」；标签缺失归入「未知艺术家/未知专辑」；粒子舞台平铺导航加入口，FB2K 目录树加「媒体库」两级节点
- **CUE 分轨**：扫描时解析同目录 .cue（UTF-8/GBK），整轨隐藏替换为虚拟分轨（`path#cueN`），分轨标题/艺术家/专辑写入 metaCache；播放按分轨区间（起止 seek），进度/时长按分轨显示，到分轨终点自动续播；上下首按分轨走
- **假无损批量检测**：Goertzel 多频点能量分析频谱截止（16k/18k 一刀切判疑似 MP3 转制），列表 ⚠ 标记（悬浮理由），批量任务可取消有进度，CSV + HTML（含频段能量 SVG）报告导出
- **播放统计**：播放 >30s 或 >50% 计一次（防刷数），累计时长记录，防抖落盘；智能列表「最常听 / 最近播放 / 最近添加」双主题入口

### 交互与界面

- **迷你模式**：主窗口形态切换（420×150 置顶小窗：封面+控制+进度），一键互切，位置记忆，托盘菜单入口
- **桌面歌词**：独立无边框透明歌词条（双行：当前+下一），锁定位置/鼠标穿透/字号/透明度调节，与双主题歌词源共用
- **Now Playing 全屏页**（N 键）：大封面 + 完整技术信息一屏（文件/格式/直通状态/后端/响度/BPM/统计/进度）+ 实时 L/R 电平条
- **拖放支持**：资源管理器拖文件/文件夹到窗口，列表行落点精确插入（金色指示线），其他区域追加队列尾部；目录递归展开、非法类型过滤提示；双主题均支持
- **命令面板（Ctrl+K）**：模糊搜索全部操作（播放/EQ/主题/配色/暗色/扫描/假无损/响度/DSD/迷你/歌词/Now Playing/设置），键盘导航回车执行
- **系统托盘**：显示主窗口/播放控制/迷你模式/桌面歌词/退出

### 流媒体融合

- **统一搜索视图**：本地曲库（置顶，格式+码率+收藏徽标）与网易云/QQ 结果同页分组；流媒体条目标注「✔ 已有本地无损/已收藏」；音质标签（标准/无损/Hi-Res/VIP）；本地结果点击直接本地播放；本地搜索框回车直达统一视图

### 工程健壮性

- **崩溃守护**：引擎子进程崩溃自动重启（指数退避 1/2/4/8s，稳定 1 分钟重置），重启后重放音质链路设置并**恢复崩溃前播放位置与队列**，UI 提示「音频引擎已自动恢复」
- **诊断包导出**：一键打包设备枚举（WASAPI/ASIO + DoP 能力）、引擎日志与错误环形缓冲（各 200 条）、设置快照、版本平台信息为 zip（自研无依赖 store-ZIP）
- **性能调试面板**（隐藏入口：标题栏版本号连击 5 次）：渲染帧率、最近扫描耗时、引擎缓冲水位、引擎运行时长、播放代际 renderGen、IPC 往返延迟，500ms 实时刷新
