## 〇、工作方式（最高优先级，先读）

   "E:\AnniePlayerTRAE\AnniePlayer-V1-Preview\app\AnniePlayerPlusProVersion"

5. 所有新功能适配融合后的统一界面（见第一、二章），遵循项目既有架构约定：引擎子进程 JSON-RPC over stdio、渲染代际 renderGen 防重入、Worker 扫描/排序、虚拟滚动、设置持久化（userData JSON + localStorage 早标记）、四配色 WCAG AA 对比度标准、动效降级 prefers-reduced-motion。「双主题」字样不再出现在任何新代码注释与文档中。

## 一、界面融合架构（最高优先级，先于一切功能开发）

### 1.1 融合目标
- 取消「双主题一键切换」，合并为单一主界面：以仿 FB2K 经典布局为主体骨架——标题栏 + 菜单栏 + 左侧目录树 + 中央播放列表 + 右侧信息栏 + 底栏控制。
- 原粒子舞台不再作为独立主题，降级为「粒子舞台覆盖层」（overlay，见 1.2）。
- 两个模式的全部既有功能必须保留，一项不许丢。功能映射表：
  - 粒子舞台四配色（暗夜金 / 靛蓝极光 / 翡翠深空 / 白昼）→ 保留为全局配色方案，设置面板卡片即时切换逻辑沿用；原 FB2K 暗色模式并入配色系统统一管理（Ctrl+Shift+D 快捷键保留，循环切换）
  - 浮动歌词层 → 在粒子覆盖层内保留
  - 频谱/波形可视化面板 → 右栏信息区保留，可停靠收起
  - BPM/调性徽章 → 右栏信息区显示 + 播放列表可选列
  - 平铺文件夹导航 → 中央区域新增「文件夹网格」视图模式，与现有列表/分栏/封面三种视图并列；浅色标注归属主文件夹、点击进入递归显示、返回栏一键回退逻辑全部沿用
  - 底栏三段分层（播放组 56px 主键 / 音频工具组 / 系统组）→ 融合后底栏沿用此分层方案A
  - FB2K 全部既有功能（虚拟滚动、列排序、分组视图、右键菜单、属性弹窗、播放列表管理、EQ 抽屉、快捷键组）原样保留
- 状态连续性：融合后不再存在主题切换，播放状态/队列天然连续；原「跨主题索引自动定位播放文件」改造为「切换视图/切换来源时自动定位」，逻辑保留。
- 原 300ms 遮罩淡切方案改作粒子覆盖层的淡入淡出动画。

### 1.2 粒子舞台覆盖层
- 三种呼出方式：
  a) 底栏系统组「粒子舞台」按钮（图标建议 ✦ 或自定义粒子图标）；
  b) 快捷键（默认 F11，设置内可改键）；
  c) 空闲自动呼出：播放中且连续 10 秒无键鼠操作（监听 mousemove / keydown / wheel / 触屏），覆盖层淡入；任何键鼠操作立即淡出回到主界面。
- 空闲规则：
  - 仅「播放中」触发，暂停/停止时不自动呼出；手动按钮/快捷键任何时候可用；
  - 空闲时长可调：5–60 秒，默认 10 秒；自动呼出可整体开关（默认开启）。
- 覆盖层形式：主窗口内容区内的全窗口覆盖（非显示器全屏独占），淡入淡出沿用 300ms 遮罩。
- 覆盖层内交互：单击任意处或 ESC 淡出；保留浮动歌词层；底部迷你控制条（播放/切曲/音量）仅在鼠标移动时浮现，静止 3 秒后自动隐藏，避免遮挡画面。
- 验收：播放后静置 10 秒自动淡入，动一下鼠标立即淡出；按钮与快捷键随时可呼出/退出；暂停后不再自动呼出；设置里改时长与开关生效。

## 二、粒子视觉系统升级（差异化重点）

### 2.1 多特征音频驱动（替换单一 BPM 驱动）
- 引擎实时向渲染进程推送分析帧：低/中/高三频段能量 + 整体 RMS 响度 + 既有 BPM（FFT 与 float PCM 数据链路现成，扩展即可）。
- 默认响应映射（参数全部可序列化）：
  - 低频能量（鼓点/贝斯）→ 粒子爆发脉冲、冲击波扩散；
  - 中频能量（人声/主奏）→ 粒子聚拢形态、整体流动方向；
  - 高频能量（镲片/泛音）→ 闪烁密度、粒子尾迹长度；
  - RMS → 全局运动速率与场景亮度。
- 目标：粒子「真的在听这首歌」，而不是按固定 BPM 自嗨。
- 验收：播放鼓点重的曲目与纯钢琴曲，粒子行为肉眼可辨地不同；频谱面板数值与粒子响应节奏一致。

### 2.2 场景系统（Scene）
- 粒子引擎之上做「场景」层：每个场景 = 一份可序列化 JSON 配置（配色、粒子数量、行为参数、响应映射权重、封面背景处理方式）。
- 内建 4–6 个场景预设（建议：星云 / 雨幕 / 极光 / 频谱柱 / Now Playing），覆盖层内可切换。
- 抗疲劳机制：「随专辑自动换场景」开关 + 歌曲段落级行为变化（依据能量对比切换粒子行为模式，避免一首歌看腻）。
- Now Playing 实现为一个场景（取代原独立全屏信息页方案）：大封面居中 + 技术信息（文件名、格式、码率、源码率/位深、输出状态、响度值、BPM/调性）低透明度环绕排布，粒子退为背景层；适合接副屏/投影常亮展示，防烧屏可做低频像素微移（可选）。
- 场景配置架构上必须可序列化 + 可导入导出（本次只需内建预设 + 架构就绪，导入导出 UI 留待后续版本）。
- 验收：切换场景粒子行为与配色明显不同；Now Playing 场景信息完整可读、频谱实时。

### 2.3 状态可视化融入视觉语言
- Bit-perfect 直通状态下，粒子带细微金色描边/金环光晕（呼应品牌金环图标）；发生引擎重采样或 DSD 转 PCM 时消失。与状态栏文字指示并存，金色描边是视觉表达、文字是精确信息。
- Crossfade 交叉淡入时，粒子做「溶解 → 重组」过渡，与音频渐变同步。
- 验收：切换直通/重采样状态时金色描边正确显隐；开 Crossfade 切歌时粒子过渡自然。

### 2.4 视觉性能管理（HiFi 用户刚需：防风扇噪音干扰听音）
- 设置新增「视觉性能档」：
  - 华丽：60fps 满粒子 + 封面模糊交叉淡入；
  - 均衡（默认）：60fps + 默认粒子数；
  - 省电：30fps + 粒子数减半 + 关闭封面模糊交叉淡入。
- 窗口最小化/失焦时粒子渲染完全挂起（backgroundThrottling + rAF 暂停），后台听歌零 GPU 占用；重新聚焦时平滑恢复。
- prefers-reduced-motion 全局降级沿用。
- 验收：任务管理器观察，最小化后 GPU 占用归零；三档切换帧率与粒子规模变化明显。

## 三、音质链路增强（优先级最高）

### 3.1 DSD 原生输出
- 现状：DSF/DFF 经 ffmpeg 转 PCM。目标：新增原生 DSD 输出能力。
- 设置面板新增「DSD 输出方式」三选一：转 PCM（现状，默认）/ DoP（DSD over PCM，经 WASAPI 独占直通）/ Native（ASIO DSD 模式）。
- DoP：PCM 帧封装 0x05/0xFA 标记，仅当检测到输出设备支持时可选，不支持则灰显并附说明。
- Native ASIO DSD：引擎 C# 侧实现 ASIO DSD 样本格式输出，设备不支持时回退并明确提示。
- 播放中切换 DSD 模式允许断流重建（明确提示用户即可），不要求无缝。
- 验收：用支持 DoP/Native 的 USB DAC 播放 DSF 文件，设备端采样率指示灯显示 DSD 原生速率；不支持设备自动回退并弹提示。

### 3.2 削波防护（DSP 链）
- 现状问题：15 段 EQ 在 float 域 ±12dB，正增益会导致输出削波。
- 在引擎 DSP 链 EQ 之后、输出之前加增益管理：
  a) 自动 preamp 补偿：根据 EQ 各段最大正增益自动施加等量负前级，开关可关；
  b) 可选输出限幅器（limiter / soft clipper）作为第二道保险。
- 设置项放在 EQ 面板内：「自动增益补偿（防削波）」开关，默认开启。
- 验收：全部频段拉 +12dB 播放高响度曲目，输出不出现可闻削波失真；独占链路内生效、热更新不断流。

### 3.3 响度归一化（ReplayGain / R128）
- 扫描 Worker 内顺带计算每轨响度（ReplayGain 或 EBU R128），结果写入 metaCache 持久化。
- 播放时引擎自动套用增益，设置项：「响度均衡：关闭 / 按曲目 / 按专辑」，默认关闭。
- 与防削波联动：归一化增益同样经过削波防护。
- 已扫描但未算响度的旧曲库，提供「补算响度」按钮，后台分批处理可取消。
- 验收：响度差异大的两首歌连播，开启后主观音量趋于一致；关闭后恢复原样。

### 3.4 Bit-perfect 直通状态显示
- UI 显眼处实时显示「源码率/位深 → 输出采样率/位深」，例如「44.1kHz/16bit → 44.1kHz/16bit」。
- 当源码率与输出一致且无任何 DSP 重采样时，显示绿色圆点 + 「Bit-perfect」字样；发生引擎重采样或 DSD 转 PCM 时变为黄色并注明原因。
- 显示位置：主界面底栏系统组附近 + 右栏信息区状态栏；Now Playing 场景（2.2）中复用同一数据源；粒子金色描边视觉表达见 2.3。
- 验收：播放不同采样率文件，显示实时准确；开启独占后切换设备，状态正确刷新。

### 3.5 缓冲与预载策略可配
- 设置新增「音频缓冲」：独占/共享链路缓冲区大小滑杆（50–500ms，默认现状值），「整轨预载到内存」开关（默认关）。
- 说明文案注明：卡顿/爆音时可调大缓冲。
- 验收：调大缓冲后冷启动播放延迟略增但播放稳定；预载开启后机械硬盘曲库切歌无卡顿。

### 3.6 交叉淡入（Crossfade）
- 引擎 DSP 链加切歌淡入淡出，设置项：开关 + 时长（0–10s，步进 0.5s，默认 0 即关闭）。
- 手动切歌与自动连播均生效；独占模式下允许以不断流方式实现（同一输出流内混音过渡）。
- 粒子视觉联动见 2.3。
- 验收：设置 3s，自动连播时两曲平滑过渡无爆音。

### 3.7（可选，时间允许再做）耳机交叉互馈 crossfeed
- 简单 Bauer 式 crossfeed 加入 DSP 链，设置项：关 / 低 / 高，默认关。不做不阻塞交付。

## 四、曲库与管理

### 4.1 媒体库视图（专辑 / 艺术家聚合）
- 在现有文件夹索引之外，新增媒体库层：利用 metaCache 标签数据构建「专辑视图」（封面网格，按专辑聚合）与「艺术家视图」。
- 入口：左侧目录树加「媒体库」节点，下挂艺术家/专辑两级；中央区域专辑封面网格作为视图模式之一，与列表/分栏/封面/文件夹网格视图并列切换。
- 标签缺失的文件归入「未知艺术家/未知专辑」，不崩溃不丢歌。
- 沿用虚拟滚动与 Worker 排序过滤，5000+ 首保持流畅。
- 验收：同一专辑分布在不同文件夹也能正确聚合；点击专辑卡片列出全部曲目。

### 4.2 CUE 分轨支持
- 解析整轨 FLAC/APE/WAV 同目录 .cue，生成虚拟分轨进入播放列表与媒体库（分轨标题、艺术家、起止时间正确）。
- 播放时按分轨区间 seek 整轨音频，波形/进度显示按分轨显示。
- 内嵌 CUE（FLAC 内嵌 cuesheet）如易支持则一并支持，否则仅外挂 .cue。
- 验收：整轨+CUE 加载后列表显示各分轨，双击分轨从正确位置播放，上一首/下一首按分轨走。

### 4.3 假无损检测批量版 + 报告
- 在现有单轨频谱分析基础上，做后台批量检测：对曲库逐轨跑频谱分析，判定「疑似假无损」（频谱高频截止特征，如 16kHz/20kHz 一刀切）。
- 列表中可疑曲目打 ⚠ 标记（悬浮显示判定理由，如「高频截止于 16kHz，疑似 MP3 256kbps 转制」）。
- 支持导出报告：CSV（文件路径、码率、截止频率、判定结论）+ 可选图文 HTML 报告（含代表频谱截图）。
- 批量任务可取消、显示进度，跑批放 Worker，不阻塞 UI 与播放。
- 验收：混入几首 MP3 转 FLAC 的测试文件，批量检测后全部正确标记，报告可导出打开。

### 4.4 播放统计
- 记录每轨播放次数、最近播放时间、累计播放时长，持久化到本地数据库/JSON。
- 新增智能列表：「最常听」（按播放次数排序）、「最近播放」、「最近添加」，入口放左侧目录树。
- 播放计数规则：播放超过 50% 或 30 秒才计一次，防切歌刷数。
- 验收：听几首歌后三个智能列表内容正确更新。

## 六、流媒体融合（融入 FB2K 主体）

### 6.1 左侧目录树：新增「流媒体」节点
- 与本地曲库节点平级，下挂：网易云音乐、QQ 音乐两个子节点。
- 每个源下挂：我的歌单（登录后）、推荐歌单/每日推荐、搜索历史。
- 未登录时显示「扫码登录」引导节点，登录逻辑沿用现有扫码方案与 VIP 感知。

### 6.2 中央区域：流媒体内容与本地同构
- 点开流媒体歌单/搜索结果 → 中央播放列表显示，列结构与本地一致（标题/艺术家/专辑/时长）+「音质」列（标准/极高/无损/Hi-Res 标签）+ 来源图标列。
- 沿用虚拟滚动、列排序、右键菜单体系；流媒体曲目右键项：播放 / 添加到播放列表 / 收藏到我的喜爱 / 查看专辑 / 复制歌曲信息。
- 流媒体封面在中央封面视图与右栏信息区正常显示。

### 6.3 播放队列：本地与流媒体混排
- 队列中两类曲目共存，来源图标区分；双击流媒体曲目经 ffmpeg 拉流解码进入同一独占链路（既有能力），15 段 EQ、频谱、响度均衡、直通状态显示等全链路生效。
- 流媒体曲目播放失败（版权/网络）时明确提示，「自动跳下一首」开关默认开。

### 6.4 统一搜索视图
- 搜索框结果页分组展示：本地命中组置顶 + 网易云组 + QQ 音乐组。
- 本地已有（曲库命中/已收藏）的曲目在流媒体结果中标注「✔ 已有本地 / 已收藏」徽标。
- 本地结果显示格式与码率；搜索范围可切换（统一 / 仅本地 / 仅流媒体），默认统一。
- 验收：搜一首本地已有的歌，本地条目置顶，流媒体条目出现徽标；点击各自走正确链路。

### 6.5 边界
- 歌单列表元数据可内存缓存加速浏览；不做音频落盘缓存（本次明确不做）。

## 七、工程健壮性

### 7.1 崩溃守护与诊断包
- 引擎子进程崩溃：自动重启引擎、恢复崩溃前播放位置与队列，UI 提示「音频引擎已自动恢复」。
- 设置面板新增「导出诊断信息」：打包设备枚举结果（WASAPI/ASIO 设备列表与能力）、引擎最近日志、最近错误栈、当前设置快照为 zip，供报障使用。
- 验收：手动 kill 引擎进程，3 秒内自动恢复播放；诊断 zip 可正常导出且内容完整。

### 7.2 性能调试面板（开发者向，设置里藏入口）
- 内部调试页显示：最近扫描耗时、大列表渲染帧率、引擎缓冲水位实时曲线、IPC（JSON-RPC）往返延迟。
- 默认隐藏，设置里连续点击版本号 5 次开启。
- 验收：开启后面板数据实时刷新，与实际操作负载吻合。
