## 一、产品简介

安妮播放器Plus Pro 是一款 Windows 本地音乐播放器，面向**音质发烧友**与**大曲库用户**：

- **bit-perfect 播放**：自研 C# 音频引擎，WASAPI 独占 / ASIO 双通道输出，源码率直通不重采样
- **DSD 原生输出**：DSF 支持 DoP 直通（DSD over PCM）
- **双主题界面**：3D 粒子舞台（视觉系）与仿 foobar2000（效率系），随时切换
- **专业工具链**：频谱分析、波形、假无损批量检测、响度归一化、节拍分析
- **流媒体融合**：网易云 / QQ 音乐在线搜索播放，与本地曲库统一视图

技术栈：Electron 42 + .NET 8 自研引擎（JSON-RPC over stdio）+ ffmpeg 解码。

## 二、安装与首次启动

1. 运行 `AnniePlayerPlusProVersion-beat0.0.1-Setup.exe`，可自定义安装目录
2. 桌面/开始菜单生成快捷方式「**安妮播放器Plus Pro**」
3. 与稳定版 / EXP 版 / Plus 版**完全隔离**（appId `com.mineradio.local.pro`），可共存，配置互不影响
4. 首次启动后：点击侧栏「**+ 添加文件夹**」选择音乐目录，自动开始扫描
5. 扫描在后台 Worker 线程进行，可继续操作；5000+ 首曲库流畅不卡

> 卸载：控制面板或开始菜单右键卸载，配置保留在 `%APPDATA%\annie-player-plus-pro`（可手动删除）。

## 六、音质链路（发烧友向）

入口：**设置面板 → 音质链路（Pro）**

### 1. 输出设备（底栏 🎧）
- **WASAPI 独占**：绕过系统混音器，源码率直通（bit-perfect）
- **ASIO**：专业声卡低延迟通道，支持控制面板呼出
- 设备热切换；不支持的采样率自动回退提示

### 2. Bit-perfect 直通状态（底栏实时显示）
- 绿点 + `44.1kHz/16bit → 44.1kHz/16bit`：源码率直通，无任何重采样
- 黄点 + 原因：引擎重采样（如 `引擎重采样至 48000Hz`）或 `DSD 转 PCM`
- FB2K 主题在右栏格式行同步显示

### 3. DSD 输出方式（DSF 文件）
| 模式 | 说明 |
|---|---|
| 转 PCM（默认） | ffmpeg 解码为 PCM，兼容性最好 |
| DoP | DSD 位流封装为 176.4kHz/24bit PCM 经 WASAPI 独占直通，DAC 识别后原生解码（设备不支持时选项灰显，播放时自动回退并提示） |
| Native | ASIO DSD 模式（需驱动支持；当前链路不支持时明确提示并回退） |

> 验证方式：支持 DoP 的 USB DAC 播放 DSF 时，DAC 采样率指示灯显示 DSD 原生速率。DFF 文件暂走 PCM。播放中切换模式于下一曲生效（断流重建）。

### 4. 削波防护（EQ 面板内）
- **自动增益补偿（默认开）**：按 EQ 各段最大正增益自动施加等量负前级，防止 +12dB 拉满时削波
- **输出限幅器（默认开）**：tanh 软膝限幅，第二道保险
- 热更新不断流；与响度归一化联动（真峰 headroom 限制）

### 5. 响度均衡（EBU R128）
- 三档：**关闭（默认）/ 按曲目 / 按专辑**，目标响度 -16 LUFS
- 首次播放某曲时后台自动分析（懒补算），结果持久化
- **补算响度**按钮：旧曲库全量后台分批分析，显示进度、可取消
- 连播响度差异大的曲目时开启，主观音量趋于一致

### 6. 音频缓冲
- 缓冲滑杆 **50–500ms**（默认 50ms）：卡顿/爆音时调大
- **整轨预载到内存**（默认关）：机械硬盘曲库切歌更稳
- 均于下一曲生效

### 7. 交叉淡入 Crossfade
- 滑杆 **0–10 秒**（步进 0.5，默认 0 关闭）
- 开启后手动切歌与自动连播均在**同一输出流内混音过渡**（独占不断流）
- 两曲采样率不同时解码端自动对齐

## 七、均衡器（15 段 EQ）

- 底栏/工具栏 EQ 按钮呼出悬浮面板

## 九、CUE 分轨

- 整轨 FLAC/APE/WAV 同目录的 `.cue` 自动解析（UTF-8/GBK 编码均支持）
- 整轨文件在曲库中隐藏，替换为**虚拟分轨**（标题/艺术家/专辑来自 CUE）
- 双击分轨从正确位置播放；进度条与时长按分轨显示
- 到分轨终点自动续播下一轨；上一首/下一首按分轨走
- 支持 seek（分轨内任意拖动）

## 十九、常见问题 FAQ

**Q：播放 DSF 时显示黄色圆点？**
A：当前为「转 PCM」模式属正常现象（注明 DSD 转 PCM）。如需原生输出，设置→音质链路→DSD 输出方式选 DoP（设备需支持 176.4kHz/24bit，不支持会自动回退）。

**Q：独占模式下系统音量无效？**
A：这是 bit-perfect 直通的特性，请用播放器内音量滑杆（引擎数字音量）。

**Q：播放卡顿/爆音？**
A：设置→音质链路→把「音频缓冲」调大（如 200ms）；机械硬盘曲库可开「整轨预载」。

**Q：EQ 拉满后声音破？**
A：确认 EQ 面板内「自动增益补偿」与「输出限幅器」均开启（默认开）。

**Q：曲库里的整轨 FLAC 不见了？**
A：同目录存在 .cue 时整轨自动替换为分轨（正常行为），删除 .cue 并重扫可恢复。

**Q：提示「音频引擎已自动恢复」？**
A：引擎曾异常退出并被崩溃守护自动重启，播放已从断点续上。若频繁出现，请「导出诊断信息」反馈。

**Q：迷你模式/桌面歌词找不到了？**
A：`Ctrl+M` 切换迷你；桌面歌词在托盘菜单或命令面板（`Ctrl+K` 输「歌词」）开关。
